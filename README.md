# Grupo de Jovens Coração Mariano (GJCM)

Site institucional desenvolvido para apresentar e divulgar o trabalho do **Grupo de Jovens Coração Mariano (GJCM)**. A proposta é aproximar a comunidade do grupo, compartilhar sua vivência e facilitar o acesso às informações sobre sua caminhada.

## ✨ Sobre o projeto

O site tem como objetivo apresentar a identidade e a atuação do Grupo de Jovens Coração Mariano, servindo como um espaço de divulgação de suas atividades e de sua espiritualidade.

Entre os conteúdos que o projeto pretende reunir estão:

- **Sobre o grupo:** sua identidade, missão e trajetória.
- **Santos de devoção:** apresentação dos santos que inspiram a espiritualidade do grupo.
- **Eventos:** divulgação de encontros, celebrações e atividades realizadas.
- **Próximos encontros:** informações para que os interessados possam acompanhar a programação.
- **Atividades e atualizações:** registros e notícias sobre o momento atual do grupo.

> “Uma verdadeira família para se viver.”

## 🛠️ Tecnologias utilizadas

O projeto utiliza as seguintes tecnologias:

- **React 19** — construção da interface em componentes.
- **JavaScript (ES Modules)** — lógica da aplicação.
- **Vite** — ambiente de desenvolvimento e ferramenta de build.
- **CSS** — estilização da interface, incluindo CSS Modules.
- **ESLint** — análise estática e padronização do código.

## 🚀 Como executar o projeto

### Pré-requisitos

- [Node.js](https://nodejs.org/) instalado.
- npm (geralmente instalado junto com o Node.js).
- Git, caso queira clonar o repositório.

### 1. Clone o repositório

```bash
git clone URL_DO_REPOSITORIO
```

### 2. Acesse a pasta do projeto

```bash
cd site-gjcm
```

### 3. Instale as dependências

```bash
npm install
```

### 4. Inicie o servidor de desenvolvimento

```bash
npm run dev
```

O Vite exibirá no terminal o endereço local para abrir o site no navegador.

## 📜 Scripts disponíveis

| Comando | Descrição |
|---|---|
| `npm run dev` | Inicia o servidor de desenvolvimento. |
